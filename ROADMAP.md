# Roadmap

This roadmap covers the open scoring methodology, evaluation framework, and reference implementation.

## 2026

### Scoring specification

- Publish definitions for all scoring dimensions
- Document weighting, aggregation, and missing-evidence rules
- Add confidence and uncertainty reporting
- Define stable machine-readable output schemas
- Introduce methodology versioning

### Evaluation

- Create a legally shareable evaluation set
- Add synthetic edge cases and regression tests
- Document calibration procedures
- Measure consistency across repeated analyses
- Establish contributor guidelines for evaluation examples

### Benchmarking and reporting

- Define genre-aware benchmarking
- Define canonical radar-chart dimensions
- Define scene-level and sequence-level heatmap metrics
- Document which measurements are descriptive versus evaluative

### Community and governance

- Establish a formal methodology proposal process
- Publish contribution and governance guidelines
- Create an initial set of open methodology questions
- Begin publishing versioned methodology releases

## 2027

### Multi-system evaluation

- Define a protocol for comparing multiple analysis models
- Measure inter-model agreement and disagreement
- Develop transparent consensus-scoring methods
- Publish model-independent evaluation reports

### Additional formats

- Identify a medium-independent scoring core
- Define screenplay-specific extensions
- Explore separate extensions for plays
- Explore separate extensions for books

### Aggregate research

- Define standards for anonymized aggregate reporting
- Document minimum sample sizes and privacy requirements
- Publish reproducible methodology reports
- Explore industry-level trend analysis without exposing private scripts

## Exploratory

- Evidence-linked feedback
- Human and model agreement studies
- Bias and genre-sensitivity audits
- Confidence calibration
- Public benchmark releases
